# Viktoria Lorang — portfolio

Portfolio site of Viktoria Lorang, UX/UI designer with 8+ years in graphic design.

Built with React + Vite, deployed on Vercel. The site plan lives in [docs/plan.md](docs/plan.md).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
```
